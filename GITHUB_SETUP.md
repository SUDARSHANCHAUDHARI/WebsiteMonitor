# GitHub Setup Checklist

Follow these steps after pushing your code to GitHub.

## Step 1: Push Code to GitHub

```bash
# Initialize git (if not already done)
git init

# Add all files
git add .

# Commit
git commit -m "Add website monitoring workflow with Slack notifications"

# Add remote (replace with your repo URL)
git remote add origin https://github.com/YOUR_USERNAME/website-monitor.git

# Push to GitHub
git push -u origin main
```

## Step 2: Enable GitHub Actions

1. Go to your repository on GitHub
2. Click **Settings** tab (top menu)
3. Click **Actions** → **General** (left sidebar)
4. Under **"Workflow permissions"**, select:
   - ✅ **Read and write permissions**
   - ✅ **Allow GitHub Actions to create and approve pull requests**
5. Click **Save**

## Step 3: Add Secrets

1. In your repository, go to **Settings** → **Secrets and variables** → **Actions**
2. Click **"New repository secret"**
3. Add these two secrets:

   **Secret 1:**
   - Name: `SLACK_BOT_TOKEN`
   - Value: Your Slack bot token (starts with `xoxb-`)
   - Click **Add secret**

   **Secret 2:**
   - Name: `SLACK_CHANNEL`
   - Value: Your Slack channel (e.g., `#alerts` or `C1234567890`)
   - Click **Add secret**

## Step 4: Test the Workflow

1. Go to **Actions** tab in your repository
2. Click **"Website Monitor & Screenshot"** in the left sidebar
3. Click **"Run workflow"** button (top right)
4. Click **"Run workflow"** (green button)
5. Wait for the workflow to complete (~1-2 minutes)
6. Check the workflow logs to verify it's working

## Step 5: Verify It's Working

### Check Workflow Run
- Go to **Actions** tab
- Click on the latest workflow run
- Verify all steps completed successfully (green checkmarks)

### Check Slack
- You should receive a notification in your Slack channel (if website is down)
- Or wait for the next scheduled run (every 15 minutes)

### Check Repository
- Go to `website-status/` folder
- You should see `latest.png` and `status.json` files
- These are auto-generated by the workflow

## Step 6: Monitor the Workflow

The workflow will automatically:
- ✅ Run every 15 minutes
- ✅ Check https://start.screencloud.com/
- ✅ Take screenshots
- ✅ Create GitHub issues if website goes down
- ✅ Send Slack notifications if website goes down

## Troubleshooting

### Workflow Not Running
- Check if Actions are enabled (Step 2)
- Verify workflow file is in `.github/workflows/` folder
- Check Actions tab for error messages

### Slack Notifications Not Working
- Verify secrets are correctly named: `SLACK_BOT_TOKEN` and `SLACK_CHANNEL`
- Check workflow logs for Slack errors
- Test your Slack token manually using `tests/test-slack.sh`

### No Screenshots Appearing
- Check workflow artifacts in Actions tab
- Verify workflow completed successfully
- Check workflow logs for errors

## That's It!

Once setup is complete, the workflow will automatically monitor your website every 15 minutes. You'll get notified via Slack and GitHub Issues if anything goes wrong.
